Claude Fable 5 is Anthropic's new flagship AI model, released June 9, 2026. It is the first publicly available “Mythos-class” model — a new tier above Claude Opus — and scores more than 10% higher than Claude Opus 4.8 on some benchmarks, according to Anthropic.

What is Claude Fable 5?

Claude Fable 5 is Anthropic's most capable generally available AI model. Announced alongside Claude Mythos 5 on June 9, 2026, it introduces a brand-new tier in the Claude line-up: where the family previously topped out at Opus, the ladder now reads Haiku → Sonnet → Opus → Fable.

The “Fable” name matters. According to Anthropic, Fable 5 is built on Mythos — the internal frontier model class whose capabilities, until now, exceeded what the company was willing to ship publicly. As TechCrunch reported, the release came just days after Anthropic publicly warned about accelerating AI capabilities — the public version ships wrapped in a new safeguard system (more on that below).

Anthropic says Fable 5's capabilities “exceed those of any model it has ever made generally available”, with the largest gains in software engineering, knowledge work, vision, and scientific research (CNBC).

“Mythos-class”: why this release is different

Until this week, Anthropic kept its most capable models internal. Fable 5 changes that — and the reason it could change is safety engineering, not just raw capability.

The public release is gated by new real-time safeguards that block responses in specific high-risk areas, including cybersecurity and biology. When a user asks a high-risk question — NBC News cites “how to make ricin” as an example — Fable 5 blocks its own response and falls back to Claude Opus 4.8 to deliver a safe answer instead.

In plain English: you get frontier-level intelligence for legitimate work, and a less capable — but safe — answer the moment a request crosses into dangerous territory. For 99% of business use cases, you will never notice the guardrail.

For developers: what changes in the API

Fable 5 is available on the Claude API and on Amazon Bedrock. It keeps the same API surface as Opus 4.7/4.8 — with one new breaking change to know about:

  • Adaptive thinking only. thinking: {type: "enabled", budget_tokens: N} returns a 400 error. Use {type: "adaptive"}.
  • New on Fable 5: an explicit thinking: {type: "disabled"} also returns a 400 (it was accepted on Opus 4.8). To run without thinking, omit the parameter entirely.
  • No sampling parameters. temperature, top_p and top_k are removed — steer with prompting instead.
  • Effort control: all 5 levels supported (low → max) via output_config.effort.
  • No assistant prefills. Use structured outputs (output_config.format) to force JSON.
# Minimal Fable 5 call (Python)
import anthropic

client = anthropic.Anthropic()

response = client.messages.create(
    model="claude-fable-5",
    max_tokens=16000,
    thinking={"type": "adaptive"},          # the only valid "on" mode
    output_config={"effort": "high"},        # low | medium | high | xhigh | max
    messages=[{"role": "user", "content": "..."}],
)

Should your business upgrade to Fable 5?

Our take after a day of testing: don't move everything — move the right workloads. At 2× the price of Opus 4.8, Fable 5 pays for itself only where extra intelligence converts into real outcomes:

  • Upgrade: complex software engineering, long-horizon autonomous agents, scientific/technical analysis, vision-heavy document work — the areas where Anthropic reports the biggest gains.
  • Stay on Opus 4.8: general assistants, content pipelines and agent loops that already perform well — same 1M context, half the price.
  • Stay on Sonnet/Haiku: classification, extraction, summarisation and high-volume workloads. Paying $50/M output tokens to tag support tickets is burning money.

How much does Claude Fable 5 cost?

US$10 per million input tokens and US$50 per million output tokens — exactly double Claude Opus 4.8 ($5/$25). It's available to enterprise customers and paid subscribers, including via Amazon Bedrock.

How is Fable 5 different from Claude Opus 4.8?

What is the context window of Claude Fable 5?

1 million tokens — roughly 750,000 words, or several large codebases at once — with up to 128,000 tokens of output in a single response.

Can developers use Claude Fable 5 via the API?

Yes. The model ID is claude-fable-5 on the Claude API and Amazon Bedrock. It uses the same API surface as Opus 4.8 — adaptive thinking only, no temperature/top_p/top_k — with one new rule: explicitly sending thinking: {type: "disabled"} returns a 400 error; omit the parameter instead.

Is Claude Fable 5 safe to use?

Anthropic shipped Fable 5 with new real-time safeguards: queries in high-risk domains (such as bioweapons or offensive cyber capabilities) are blocked, and the system falls back to Claude Opus 4.8 to deliver a safe answer. This safeguard architecture is what made the public release possible.
